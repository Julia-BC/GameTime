# 🛡️ GameTime

Plataforma interativa e gamificada para organização de tarefas diárias e controle de tempo de tela.

## 🚀 Sobre o Projeto
O **GameTime** transforma a rotina de tarefas em uma experiência inspirada em RPG e Dashboards de conquistas, permitindo converter tarefas concluídas em minutos de uso de tempo de tela, com limites diários, poupança para fim de semana e painel administrativo.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Backend & Banco de Dados:** Supabase (PostgreSQL) com RLS (Row Level Security)
